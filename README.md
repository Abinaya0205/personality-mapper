# 🧠 Personality Mapper

## 📌 Project Overview

**Personality Mapper** is a powerful Natural Language Processing (NLP) based application that analyzes personality traits from text, voice, or files.

The application predicts the **Big Five Personality Traits** (OCEAN model) - Openness, Conscientiousness, Extraversion, Agreeableness, and Neuroticism.

This project is developed using **Python**, **Streamlit**, and **NLP libraries**.

---

## 🚀 Features

- 📝 **Text Analysis** - Type text and analyze personality instantly
- 🎤 **Voice Input** - Speak into microphone and get insights
- 📂 **CSV Upload** - Upload multiple texts for batch analysis
- 🌐 **Multilingual** - Translate between 6+ languages
- 📊 **Visual Results** - View personality scores with text bars
- 📜 **History** - Auto-saves analysis history for reference
- 🔍 **Personality Type** - Get MBTI-like personality type (ENFJ, INTJ, etc.)

## ⚙️ How It Works

1. **User** opens the Personality Mapper web app.
2. **User** chooses input method (Text / Voice / CSV / Translation).
3. **User** enters text, speaks, or uploads file.
4. **System** processes text using NLP techniques:
   - Sentiment Analysis (VADER)
   - Keyword Categorization
   - Linguistic Feature Extraction
5. **System** calculates scores for 5 personality traits (0-100%).
6. **System** determines personality type (e.g., ENFJ, INTJ).
7. **Results** are displayed with text bars and charts.
8. **History** is saved automatically.
